Project Overview

StreamFlix is a full-featured streaming platform that provides a Netflix-like experience for browsing, searching, and watching movies and TV shows. It aggregates content metadata from TMDB (The Movie Database) and provides a polished streaming experience with user accounts, profiles, watchlists, and cross-device synchronization.

Key Value Propositions

  • No subscription required — Free to use
  • Multi-profile support — Like Netflix, each user can have multiple profiles
  • Continue watching anywhere — Progress synced via Firestore
  • Release notifications — Get notified when new seasons/episodes drop
  • Desktop & Mobile apps — Electron for desktop, Capacitor for Android
  • Modern tech stack — React 19, TanStack Start, Tailwind CSS 4

What StreamFlix is NOT

  • A content hosting platform — it does not host video files
  • A piracy tool — it uses TMDB for metadata only
  • A backend CMS — it's a frontend that consumes TMDB + Firebase

Firestore Security Rules

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /movie_sources/{docId} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.token.admin == true;

Data Transformation (tmdb.server.ts)

The toMovie() and toTv() functions transform raw TMDB responses into the unified Movie type:

export function toMovie(m: any): Movie {
  const credits = m.credits;
  const castRaw = (credits?.cast || []).slice(0, 20);
  // ... extract cast, director, trailer, etc.
  return {
    id: String(m.id),
    title: m.title,
    description: m.overview || "No description available.",
    year: m.release_date ? new Date(m.release_date).getFullYear() : new Date().getFullYear(),
    rating: extractCertification(m),
    runtime: m.runtime ? `${Math.floor(m.runtime / 60)}h ${m.runtime % 60}m` : "2h",
    genres: (m.genres || []).map((g: any) => g.name),
    poster: m.poster_path ? `${IMG_BASE}w500${m.poster_path}` : "",
    backdrop: m.backdrop_path ? `${IMG_BASE}original${m.backdrop_path}` : "",
    // ... more fields
  };
}

Caching

const CACHE = new Map<string, { data: any; expiry: number }>();
const CACHE_TTL = 10 * 60 * 1000; // 10 minutes

function cacheGet(key: string): any | undefined {
  const entry = CACHE.get(key);
  if (!entry) return undefined;
  if (Date.now() > entry.expiry) { CACHE.delete(key); return undefined; }
  return entry.data;
}

Authentication System

Auth Flow

1. User visits /auth
2. Email/password or Google sign-in
3. Firebase Auth creates/returns user
4. onAuthStateChanged listener fires
5. Route guard (_authenticated/route.tsx) validates
6. User context provided to all child routes

Route Guard (src/routes/_authenticated/route.tsx)

export const Route = createFileRoute("/_authenticated")({
  ssr: false,
  beforeLoad: async ({ location }) => {
    const user = await waitForUser(); // Waits for onAuthStateChanged
    if (!user) {
      throw redirect({ to: "/auth" });
    }
    // Check for forced password upgrade
    let pending = localStorage.getItem("sf:upgrade_password") === "1";
    if (pending && location.pathname !== "/force-password") {
      throw redirect({ to: "/force-password" });
    }
    return { user };
  },
  component: () => <Outlet />,
});

Password Policy

  • Minimum 8 characters
  • At least 1 uppercase, 1 lowercase, 1 number, 1 special char
  • Enforced client-side (PasswordPolicyChecklist component)
  • Server-side validation on signup/reset

Fetching Video Source

export async function getVideoSource(tmdbId: string): Promise<VideoSource | null> {
  const snap = await getDoc(doc(db, "movie_sources", tmdbId));
  if (!snap.exists()) return null;
  return { id: snap.id, ...snap.data() } as VideoSource;
}

Playback Flow

  1. User navigates to /watch/:id
  2. Route loader calls getVideoSource(id)
  3. If found, passes video_url to VideoPlayer component
  4. VideoPlayer uses hls.js for HLS playback
  5. Progress tracked via continue-watching-firestore.ts
  6. Subtitles loaded if available

Troubleshooting

Port 8080 in Use

Change port in vite.config.ts or kill the process:

# Windows
netstat -ano | findstr :8080
taskkill /PID <PID> /F

# Mac/Linux
lsof -i :8080
kill -9 <PID>

Firebase Auth Not Working

  • Check all VITE_FIREBASE_* env vars
  • Verify authorized domains in Firebase Console
  • Ensure Email/Password provider is enabled
  • Check browser console for specific errors

TMDB API Errors

  • Verify TMDB_API_KEY (server) and VITE_TMDB_API_KEY (client)
  • Check rate limits: 40 requests/10 seconds per IP
  • Server cache (10 min) helps mitigate
  • Check tmdb.server.ts for error logs

Build Fails

  • Run npm run lint and npm run format
  • Check TypeScript errors: tsc --noEmit
  • Clear node_modules and reinstall
  • Check Node.js version (20+ required)

Electron Won't Start

  • Ensure npm run build completed first
  • Check electron/main.cjs for path issues
  • Try ELECTRON_START_URL=... npx electron .

Capacitor Sync Issues

  • Run npm run mobile:sync after config changes
  • Clean Android: cd android && ./gradlew clean
