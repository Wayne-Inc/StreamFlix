1. Project Overview

StreamFlix is a modern web-based streaming platform that aggregates movie and TV show content from various embed providers. It provides a Netflix-like browsing experience with personalized recommendations, continue watching, user profiles, and more.

Key Capabilities

  • 🎥 Browse movies & TV shows with TMDB metadata
  • 👤 Multi-profile support with PIN protection & kids mode
  • ▶️ Embedded video playback from multiple providers
  • 📺 Continue watching with progress sync (localStorage + Firestore)
  • ❤️ My List (watchlist) with optimistic UI updates
  • 🤖 AI-powered recommendations via NVIDIA Nemotron
  • 🔍 Search with debounced TMDB queries
  • 📱 Responsive design (mobile, tablet, desktop)
  • ♿ Accessible UI with proper ARIA attributes
  • 🛡️ Firebase App Check for API protection

4. Routing (TanStack Router)

File-based routing with full type safety. Routes are defined in src/routes/ and the route tree is auto-generated.

Route Hierarchy

/
├── /                          # Landing page (public)
├── /auth                      # Sign in / Sign up
├── /tos                       # Terms of Service
├── /privacy-policy            # Privacy Policy
├── /_authenticated/           # Protected layout (requires auth)
│   ├── /browse                # Main browse page
│   ├── /explore               # Genre exploration
│   │   └── /$genreId          # Genre detail page
│   ├── /movie/$id             # Movie/TV detail page
│   ├── /watch/$id             # Video player page
│   ├── /profiles              # Profile selection/management
│   ├── /settings              # User settings
│   └── /person/$id            # Actor/actress detail
└── /api/                      # Serverless API routes
    ├── /proxy                 # TMDB proxy
    ├── /send-notification     # Push notifications
    └── /verify-recaptcha      # Turnstile verification

Route Features

  • Layout Routes - _authenticated wraps protected pages
  • Loaders - Server-side data fetching with loader property
  • Search Validation - Zod schemas via validateSearch
  • Pending Components - Skeletons while loading
  • Error Boundaries - Per-route error components

5. Authentication & User Management

Auth Methods

MethodImplementation
Email/PasswordFirebase Auth with custom password policy
Google OAuthFirebase GoogleAuthProvider with account linking
GitHub OAuthFirebase GithubAuthProvider with account linking

Password Policy

  • Minimum 8 characters
  • At least 1 uppercase, 1 lowercase, 1 number, 1 special character
  • Real-time strength meter on signup
  • Force upgrade flow for weak existing passwords

Profile System

  • Up to 5 profiles per account
  • Custom name, avatar (upload, TMDB picker, or initials)
  • Color theme selection (hidden when avatar set)
  • Kids mode with content filtering
  • Optional 6-digit PIN protection
  • Parental content rating limits (G → NC-17)

Session Management

7. Key Components

MovieCard

Universal movie/TV display card with two layouts:

  • Portrait (175-220px) - Grid/browse view
  • Landscape (280-380px) - Carousel/trending view

Features: lazy images, hover overlays, play button, My List toggle, progress bar, rank badge, reason tag.

Row / RowSkeleton

Horizontal scrolling carousel with responsive skeleton matching actual card dimensions at all breakpoints (sm, md, lg, xl, 2xl).

TmdbAvatarPicker

Tabbed modal for profile pictures:

  • Your Characters - Actors from watch history
  • Popular Actors - TMDB trending people (infinite scroll)
  • Search - Debounced TMDB person search

ScreenSaver

Activates after 5 minutes of inactivity (non-mobile, non-watch pages). Ken Burns backdrop animation with title logos, metadata badges, and TV show season/episode display.

Watch Page Player

  • Multiple embed server fallback
  • iframe sandbox for security
  • Picture-in-Picture support
  • Autoplay next episode (TV)
  • Subtitle/caption support
  • Progress sync via postMessage + Firestore

Skeleton System

Comprehensive skeleton components matching real UI at all breakpoints:

  • MovieCardSkeleton - Portrait & landscape
  • HeroBannerSkeleton - Landing hero
  • RowSkeleton - Carousel rows
  • ProfileSkeleton - Profile page
  • SeasonEpisodePickerSkeleton
  • SettingsSectionSkeleton
  • ContinueWatchingSkeleton
  • MyListSkeleton
  • CalendarSkeleton

8. Core Features

Continue Watching

  • Local-first (localStorage) with Firestore sync
  • Progress saved every 5 seconds during playback
  • Cross-device sync via Firestore
  • Episode-level tracking for TV shows
  • Auto-cleanup of old entries (max 50)

My List (Watchlist)

  • Optimistic UI updates
  • localStorage + Firestore sync
  • Cross-tab event broadcasting
  • Dedicated My List page with grid layout

9. Security & Privacy

Firebase App Check

reCAPTCHA v3 provider initialized in lib/firebase.ts:

if (typeof window !== 'undefined' && import.meta.env.VITE_APP_CHECK_SITE_KEY) {
  initializeAppCheck(app, {
    provider: new ReCaptchaV3Provider(import.meta.env.VITE_APP_CHECK_SITE_KEY),
    isTokenAutoRefreshEnabled: true,
  });
}

Requires VITE_APP_CHECK_SITE_KEY in environment. See App Check Setup Guide.
