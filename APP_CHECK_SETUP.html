🔐 Firebase App Check Setup Guide

Complete guide to configuring Firebase App Check with reCAPTCHA v3 for StreamFlix

Overview

Firebase App Check protects your backend APIs from abuse by ensuring requests originate from your genuine app. StreamFlix uses reCAPTCHA v3 as the attestation provider.

What it protects: Firestore reads/writes, Auth operations, Cloud Functions, Storage uploads
Required for production. Without App Check, your Firebase project is vulnerable to credential stuffing, scraping, and billing attacks.

Prerequisites

  • Firebase project with Authentication and Firestore enabled
  • Google Cloud project linked to Firebase
  • Domain(s) where StreamFlix will run (e.g., streamflix.dpdns.org, localhost for dev)

Step-by-Step Setup

Create reCAPTCHA v3 Site

  1. Go to Google Cloud reCAPTCHA Console
  2. Click Create (or + Create)
  3. Fill in:
    • Label: StreamFlix Web
    • reCAPTCHA type: Score based (v3)
    • Domains: Add your domains:
      • streamflix.dpdns.org
      • localhost (for development)
      • Any preview/staging domains
  4. Accept terms and click Submit
  5. Copy both keys:
    • Site Key → goes in VITE_APP_CHECK_SITE_KEY (client-safe)
    • Secret Key → NEVER in client code; used server-side if needed

Register App in Firebase App Check

  1. Open Firebase Console → Your Project
  2. Navigate to Build → App Check
  3. Click Get started or Add app
  4. Select Web app (or your existing web app)
  5. Choose reCAPTCHA v3 as provider
  6. Paste the Site Key from reCAPTCHA console
  7. Click Save

Configure Environment Variables

Add to your .env.local (development) and Vercel Project Settings (production):

# Client-side (VITE_ prefix required)
VITE_APP_CHECK_SITE_KEY="your-recaptcha-v3-site-key"
Never commit this file. Use .env.local (gitignored) locally.

Enforce App Check (Production)

  1. In Firebase Console → App Check, wait for metrics to show requests (may take 10-15 min)
  2. For each service (Firestore, Auth, Functions, Storage):
    • Click the ⋮ menu → Enforce
    • Confirm enforcement
Test in audit mode first! Enforcement blocks requests without valid tokens. Monitor the App Check metrics dashboard for 24-48 hours before enforcing.

Verify Implementation

  1. Run locally: npm run dev
  2. Open DevTools → Console → Filter by App Check
  3. You should see: [App Check] Initialized with reCAPTCHA v3
  4. In Network tab, filter by exchangeRecaptchaV3Token — should return 200 OK with a token

Code Implementation

StreamFlix initializes App Check in src/lib/firebase.ts:

import { initializeAppCheck, ReCaptchaV3Provider } from "firebase/app-check";

if (typeof window !== 'undefined' && import.meta.env.VITE_APP_CHECK_SITE_KEY) {
  initializeAppCheck(app, {
    provider: new ReCaptchaV3Provider(import.meta.env.VITE_APP_CHECK_SITE_KEY),
    isTokenAutoRefreshEnabled: true,
  });
}

Key Points

  • Client-side only — guarded by typeof window !== 'undefined'
  • Auto-refresh enabled — tokens refresh before expiry
  • Lazy initialization — only runs when env var present
  • Debug token (dev) — for local testing without reCAPTCHA: 
    // In browser console during development:
self.FIREBASE_APPCHECK_DEBUG_TOKEN = 'YOUR_DEBUG_TOKEN';
// Get debug token from Firebase Console → App Check → Debug tokens

Troubleshooting

  • Set to true in initialization
    • SymptomCauseFix
    AppCheck: ReCAPTCHA error CSP blocking google.com/recaptcha Add https://www.google.com, https://www.gstatic.com, https://www.recaptcha.net to CSP script-src, connect-src, frame-src
    AppCheck: Fetch failed CSP blocking content-firebaseappcheck.googleapis.com Add https://content-firebaseappcheck.googleapis.com to connect-src
    Token not refreshing isTokenAutoRefreshEnabled: false
    Localhost blocked Domain not in reCAPTCHA allowlist Add localhost to reCAPTCHA site domains
    403 on Firestore writes App Check enforced but token invalid Check browser console for errors; verify Site Key matches

    CSP Configuration (vercel.json)

    Required additions for App Check to work:

    script-src:  ... https://www.google.com https://www.gstatic.com https://www.recaptcha.net;
connect-src: ... https://www.google.com https://www.gstatic.com https://www.recaptcha.net https://content-firebaseappcheck.googleapis.com;
frame-src:   ... https://www.google.com https://www.recaptcha.net;
img-src:     ... https://www.gstatic.com;

    Monitoring & Metrics

    • Firebase Console → App Check — Request volume, validity rate, enforcement status
    • reCAPTCHA Admin Console — Score distribution, traffic by domain
    • Vercel Analytics — Client-side error tracking
    Target: > 99% valid token rate. If dropping, check for CSP issues or bot traffic.

    Security Best Practices

    1. Rotate keys annually — Generate new reCAPTCHA site/secret keys
    2. Monitor score thresholds — reCAPTCHA v3 returns 0.0–1.0; Firebase handles threshold
    3. Use debug tokens only locally — Never in production
    4. Combine with Turnstile — App Check protects APIs; Turnstile protects auth forms
    5. Enable on all Firebase services — Auth, Firestore, Functions, Storage
